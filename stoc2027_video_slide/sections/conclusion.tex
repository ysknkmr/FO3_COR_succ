\begin{frame}{Summary}

\KEY{Result} \ Tarski's translation from \FOthree{} to \CoR{} is optimal in the worst case:
\begin{itemize}
  \item some \FOthree{} formulas of size $O(k)$ need $\ge 2^{k-1}$ compositions in every equivalent \CoR{} term,
    even with complement, converse, and shared subterms;
  \item the same technique: \FOthree{} vs.\ \FOtwo{}, matrix query languages, \CoR{} with closure.
\end{itemize}

\KEY{Technique} \ $2^k$ folds of one reference structure; each composition notices $\le 2$ of them.
