\begin{frame}{Conclusion}

\KEY{Result} \ Tarski's translation from \FOthree{} to \CoR{} is optimal in the worst case:
\begin{itemize}
  \item some \FOthree{} formulas of size $O(k)$ need $2^{\Omega(k)}$ compositions in every equivalent \CoR{} term,
    even with complement, converse, and shared subterms;
  \item the same technique: \FOthree{} vs.\ \FOtwo{}, matrix query languages, \CoR{} with closure.
\end{itemize}

\KEY{Technique} \ $2^k$ flips of one structure $\M_0$; each composition newly distinguishes $\le 2$ of them.
